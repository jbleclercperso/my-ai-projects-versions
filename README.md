# My AI Projects — versions

Ce dépôt ne contient que les installateurs de l'appli de bureau **My AI Projects** (Windows et Mac),
publiés à chaque nouvelle version. Le code source n'est pas ici.

- **Windows** : télécharge `My-AI-Projects-…-Windows.exe` dans la dernière version (onglet *Releases*). Les mises à jour se font ensuite toutes seules.
- **Mac** : télécharge le `.dmg` qui correspond à ton Mac (`arm64` = puce Apple M1/M2/M3…, `x64` = Intel). Au premier lancement : clic droit sur l'appli › *Ouvrir*. Quand une nouvelle version sort, l'appli te le dit et ouvre le téléchargement.
